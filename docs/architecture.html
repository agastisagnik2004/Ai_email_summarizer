EMBRIFY · AI EMAIL SUMMARIZER · SYSTEM ARCHITECTURE

How the whole thing fits together

One laptop does everything: a plain web page, a small Python server and six local models sharing a 6 GB GPU. No cloud, no API keys — every email, vote and recording stays on this PC.

WHO DOES THE WORK

  • Your fine-tuned model (Custom-vN)
  • Original Qwen2.5-0.5B-Instruct
  • Reply model (SFT + DPO)
  • Voice models (Whisper, Kokoro)
  • Plain rules, no AI
  • You

Start Embrify.bat

double-click on any Windows PC
  1. Find Python 3.10–3.12, or install 3.12
  2. Private env in %LOCALAPPDATA%\Embrify
  3. PyTorch (CUDA or CPU) + requirements.txt
  4. setup_models.py fetches missing models
  5. Start the server, open the browser
